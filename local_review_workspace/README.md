# Local Review Workspace

Use this folder for local testing and customer-style review.

- `normal_videos/`: put videos that should not produce theft alerts.
- `suspicious_videos/`: put videos that contain suspicious/shoplifting behavior for private evaluation.
- `evaluation_log.csv`: the app writes your post-run evaluation answers here.

Do not send this whole folder to customers. Send only the review package ZIP generated from the results page.
