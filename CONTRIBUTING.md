# Contributing

This repository is maintained as a portfolio project. Visitors may review the
work, open an issue, or propose a pull request, but direct write access is not
granted.

Before proposing a change:

1. Open an issue describing the problem or improvement.
2. Keep the change focused on one topic.
3. Explain how the change was tested.
4. Do not commit generated files, credentials, or large unrelated assets.

Submitting a proposal does not guarantee that it will be merged.
